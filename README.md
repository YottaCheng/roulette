# Python 轮盘赌策略实验平台

这是一个用于模拟和分析轮盘赌下注策略的软件平台。项目的设计核心是将游戏的核心逻辑（Engine）与用户界面（GUI）分离，以便于进行大规模的自动化测试和算法验证。

## 项目结构

* `roulette.py`: **轮盘核心规则**
    * 定义了轮盘的基本元素，如数字、颜色以及输赢的判定规则。

* `bet.py`: **主应用程序**
    * 包含 `GameEngine` 类：负责管理所有游戏逻辑，包括资金、下注、历史记录和游戏流程。这是策略分析的核心。
    * 包含 `RouletteBettingGUI` 类：负责提供一个图形化界面，用于手动操作和观察游戏过程。

* `play_pro.py` / `play.py`: **辅助观察工具**
    * 提供额外的可视化界面，用于不同的模拟和观察目的。

## 如何运行

项目的主要入口是 `bet.py`。

```bash
python bet.py
