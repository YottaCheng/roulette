# Python 轮盘赌策略平台 (v4.0)

这是一个使用 Python 和 Tkinter 构建的、功能全面的轮盘赌模拟器与测试平台。该项目的设计核心是将游戏逻辑引擎与用户界面清晰地分离，从而实现稳健的测试，并为未来扩展到自动化策略代理（Agent）提供了可能。

## 主要功能

- **双模式轮盘**：支持美式轮盘（含 '0' 和 '00'）和欧式轮盘（仅含 '0'）。
- **完整的投注类型**：
    - **1:1 赔率**：红/黑、奇/偶、大/小 (1-18, 19-36)。
    - **2:1 赔率**：打（1-12, 13-24, 25-36）和列。
    - **35:1 赔率**：押注单个数字。
- **多重下注能力**：用户可以在一轮中同时进行多个不同的投注。
- **精美的图形用户界面 (GUI)**：一个现代化的、用户友好的界面，用于管理资金、下注和查看历史记录。其特色功能包括一个用于轻松选择单个号码的弹出式数字键盘。
- **全面的单元测试**：项目包含一个专门的测试套件，用于验证所有投注场景和边界情况下的游戏逻辑准确性。

## 项目架构

该项目被特意分成了几个职责清晰的独立文件：

-   `roulette.py`: **规则手册**。这个核心模块定义了 `RouletteWheel` 类，其中包含了游戏的基本规则，如数字、颜色、列布局，以及判断投注输赢的逻辑。
-   `bet.py`: **后端引擎**。该文件包含 `GameEngine` 类。它是应用程序的大脑，负责管理玩家的余额、跟踪投注、计算利润并维护游戏状态。这是一个非可视化的组件。
-   `bet_ui.py`: **主应用程序 (前端)**。这是用户进行交互的主要用户界面。它导入 `GameEngine` 并提供所有的视觉元素（按钮、标签等）。**这是您需要运行以进行游戏的文件。**
-   `test.py`: **质量检查器**。该文件包含使用 Python 内置的 `unittest` 框架编写的自动化测试套件。它严格测试 `GameEngine`，以确保所有的计算和游戏逻辑都是正确的。
-   `play.py`: **一个更简单的替代模拟器**。这是一个独立的、功能更基础的GUI应用程序，用于进行没有投注环节的简单旋转模拟。

## 如何使用

本项目仅使用 Python 标准库，无需安装任何外部依赖。

1.  **运行主投注平台**：
    ```bash
    python bet_ui.py
    ```

2.  **运行自动化测试套件**：
    ```bash
    python -m unittest test.py
    ```
